# LifeWork

> **개인 맞춤형 업무 중 자세 교정 시스템**
> 웹캠 자세 추정과 압력 센서를 함께 사용해 VDT 증후군을 예방하고 개선하는 웹 서비스

![웹페이지 화면 예시](https://github.com/aeri123443/LifeWork/assets/93986687/733d0c7d-34b7-4f04-a986-0ced79fef762)

- 2023-2학기 캡스톤디자인 (2023년 대전대학교 LINC3.0 사업 글로벌 캡스톤디자인)
- 기간: 2023.09 ~ 2024.01
- 3인 팀

## 배경

모니터 앞에서 오래 일하는 사람에게 거북목, 손목 터널 증후군 같은 VDT 증후군이 늘고 있습니다.
기존 자세 교정 제품은 카메라나 웨어러블 센서 하나에만 의존하는 경우가 많아서, 사용자의 환경이나 체형에 따라 정확도가 흔들렸습니다.
LifeWork는 **사용자 본인의 초기 바른 자세를 기준값으로 저장**하고, **카메라와 압력 센서를 함께 사용해** 개인별로 자세를 판정합니다.

## 주요 기능

- **기준 자세 등록**: 처음 사용할 때 바른 자세를 측정해 사용자별 기준 점수로 저장
- **실시간 모니터링**: 웹캠 자세 추정과 손목 압력 센서 값을 기준과 비교하고, 바르지 않은 자세가 감지되면 웹에서 경고
- **자세 점수**: 자세 상태를 점수로 환산해 현재 수준을 한눈에 확인
- **기간별 통계**: 일간·주간·월간 자세 점수 변화 추이 시각화
- **개인정보 보호**: JWT 인증과 비밀번호 암호화

## 시스템 구성

```
[Arduino + FSR402 압력 센서] ──(BLE, HM-10)──┐
                                              ├──▶ [Web: 모니터링·통계 화면] ──(REST)──▶ [Server: Express] ──▶ [MySQL]
[웹캠 + PoseNet(TensorFlow.js)] ─────────────┘
```

| 디렉토리 | 내용 | 기술 |
|---|---|---|
| `web/` | 로그인·회원가입, 기준 자세 등록, 실시간 모니터링, 통계 화면 | HTML/CSS/JavaScript, Chart.js, d3, TensorFlow.js(PoseNet), Web Bluetooth |
| `db/` | 사용자·자세 점수 API 서버 | Node.js, Express, MySQL, JWT, bcrypt |
| `hw/` | 압력 센서 측정값 평균 산출 및 BLE 전송 | Arduino, FSR402, HM-10 |

## 실행 방법

```bash
# 서버
cd db
npm install
npm start          # nodemon app

# 웹
# web/index.html을 정적 서버(예: VS Code Live Server)로 실행
```

- 서버 주소는 `http://127.0.0.1:8080`을 기준으로 작성되어 있습니다.
- Web Bluetooth API를 사용하므로 Chrome 브라우저에서 실행해야 합니다.
